# One-minute demo

1. Open screenwriting.html through the local HTTP server.
2. Choose Feature Film, set the title to Coffee Shop Demo, and edit one line.
3. Add a note, click Save, reload, and choose Coffee Shop Demo from Recent Scripts. Verify the draft and note restore.
4. Click Play Dialogue, then Stop Playback. Voice availability depends on the browser.
5. Click Download Backup to obtain a JSON copy.
6. Click Print / PDF and choose Save as PDF in the browser's print dialog.

The example screenshot and printed PDF use synthetic demonstration dialogue. They do not represent user research or usage metrics.
